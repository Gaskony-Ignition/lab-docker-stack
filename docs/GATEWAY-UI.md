# Driving a gateway's UI headlessly

Gateway Network pairing, EAM setup, MQTT config, the module certificate wizard
and the trial reset are all UI-only in 8.3 — there is no file to edit or REST
route for some of them. `scripts/ign-gw.js` drives them with Playwright:

```
node scripts/ign-gw.js explore --gateway local --path /app/config/... --settle 5000
node scripts/ign-gw.js trial-reset --gateway local-edge1
node scripts/ign-gw.js api --gateway local --path /data/api/v1/gateway-info
```

`--gateway` names a stanza in `.gateways.env` (`local`, `local-edge1`,
`local-edge2`), generated by `make env` from `.secrets.env` and gitignored.
Credentials never go on the command line.

## Prefer the REST API to the DOM, and find the call by tracing it

Several config grids cannot be driven headlessly at all — they are divs rather
than tables and their row menus render in portals, so a click reports success
and changes nothing. Three rules make the API route reliable:

- **Trace, don't guess.** `explore --trace` logs the calls a page makes. A
  page's real endpoints often live in a lazily-loaded chunk that is not in the
  importmap; `TRACE_ALL=1` keeps that JS in the trace so you can find
  `/res/sys/js/gateway/<Page>.chunk.bundle.js` and read it.
- **Reading and writing a record are different endpoints.** The generic
  `/data/api/v1/resources/list/<module>/<type>` reads, but the matching `PUT`
  may not exist — Gateway Network approval, for example, has its own
  `PUT /data/api/v1/gateway-network-incoming/toggleApproval/<remoteId>/<bool>`.
- **Writes need `X-CSRF-Token`**, from `GET /data/app/session`. Without it 8.3
  answers 403 on a fully authenticated session, which reads like a permissions
  problem and is not one.

Verify from a second source rather than the response code — re-read the list
you just wrote to, or read the same state off disk.

## SPA timing and selector traps

- **`networkidle` never fires** — the gateway app polls continuously. Use
  `domcontentloaded` and then wait for a specific element.
- **The nav and trial banner render late.** Checking for a control immediately
  after load finds nothing on a page that visibly has one a moment later.
- **Decide "already logged in" from the API, not the DOM.**
  `GET /data/api/v1/gateway-info` is 401 anonymous, 200 authenticated. A DOM
  signal races the late render and can report an anonymous session as
  authenticated, after which every later step fails as if it were a
  permissions problem.
- **A text selector can be ambiguous** — an expired-trial banner's "Log In to
  Reset" button also matches a bare `text=Log In`. Match the anchor, not the
  words.

Login is a two-page flow advanced by clicking **CONTINUE**, not Enter. Edge
gateways have a reduced UI: `/app/platform/system/licensing` 404s there, so the
trial reset falls back to the banner control.

## Config resources, `enabled`, and its three lies

Toggling a config resource's `enabled` attribute from Jython:

- `getAttribute("enabled")` is declared `Optional<JsonElement>` and hands back
  a **plain Python bool**, so `getAsBoolean()` raises `AttributeError` — read
  it through `str()`.
- The resource reports the **overlay** collection it was read through
  (`local`), not the one that defines it (`core`), and pushing to the overlay
  is refused with `MODIFY illegal: '...collectionName=local' doesn't exist` —
  which reads as a missing resource while the REST API lists it happily. Use
  `getDefiningCollectionName()`.
- The **signature carries a ResourceId too**, stamped with the same overlay
  collection, so fixing only the resource swaps that error for
  `MODIFY illegal: signature mismatch`. Rebuild the signature against the
  corrected id, keeping its bytes as the lock.

All three fail silently behind a caught exception, so check the log rather
than trusting a clean return.
